> craggy-charts_

Design prototype. Every chart is drawn in the Craggy tile grid; the code under each card is the exact call that renders it. Hover for tooltips, click legend keys to toggle series.

Tile size
6px
Prototype renderer: Canvas2D, one shared animation loop, idle charts cost nothing. v1 replaces the draw step with WebGL2 (web) and drawRawAtlas (Flutter); see PLAN.md.
